# Proyectos-universidad
Bienvenido/a a mi repositorio principal, donde centralizo todos los proyectos, laboratorios y evidencias desarrollados a lo largo de mis estudios universitarios en ciberseguridad e informática. Este espacio funciona como un portafolio vivo: aquí documento tanto los resultados finales como el proceso de aprendizaje detrás de cada proyecto, incluyendo la investigación previa, la configuración de entornos, los comandos y scripts utilizados, los errores encontrados y las lecciones aprendidas.

## Propósito de este repositorio
* Centralizar todos mis trabajos académicos en un solo lugar, organizados por área temática.

* Documentar cada proyecto con su contexto, objetivos, metodología y resultados.

* Demostrar de forma práctica las competencias técnicas adquiridas durante la carrera.

* Servir de referencia futura para repasar comandos, configuraciones y metodologías aplicadas.

* Compartir con la comunidad estudiantil materiales que puedan ser útiles para otras personas que estudian ciberseguridad.

## Áreas temáticas cubiertas

Pruebas de penetración (Pentesting)
* Proyectos enfocados en metodologías de explotación de vulnerabilidades sobre entornos controlados de laboratorio, incluyendo reconocimiento, escaneo, enumeración, explotación, escalada de privilegios y generación de reportes. Uso de herramientas como Nmap, Metasploit, Burp Suite, Hydra, John the Ripper y aplicaciones de práctica como DVWA, TryHackMe, Hack The Box y VulnHub.

Análisis y monitoreo de seguridad (SOC / Blue Team)
* Ejercicios de análisis de incidentes, correlación de alertas y generación de reportes de seguridad. Experiencia con SIEM, revisión de logs, análisis de tráfico de red con Wireshark, y elaboración de reportes técnicos orientados a la respuesta a incidentes.

Automatización y orquestación (SOAR)
* Proyectos que integran herramientas de Security Orchestration, Automation and Response para la automatización de flujos de respuesta a incidentes, reducción de tiempos de reacción y creación de playbooks de seguridad.

Administración de sistemas Linux y Windows
* Configuración y hardening de servidores, despliegue de servicios (DNS, DHCP, HTTP, SSH, FTP), administración de usuarios y permisos, y aplicación de buenas prácticas de seguridad sobre Kali Linux, Debian y Windows Server.
  
Active Directory y seguridad en redes corporativas
* Despliegue de controladores de dominio, gestión de políticas de grupo (GPO), estructura de bosques y dominios, y ejercicios de seguridad orientados a entornos corporativos basados en Active Directory.

### Seguridad y ética
Todos los proyectos aquí publicados fueron realizados en entornos de laboratorio controlados o plataformas diseñadas para el aprendizaje, con fines exclusivamente educativos. Se siguen principios de hacking ético y buenas prácticas de la industria.
